# Simulation results

Generated by `python -m smartdialer.sim`. 100 agents unless noted, seed 1, virtual time (no sleeping), real PostgreSQL, mock providers A and B. Every number below comes from the database after the run; nothing is estimated.

**Columns.** *Util* = share of online agent-seconds spent CONNECTED to a borrower (the number that predictive dialing exists to raise). *Util (>3 min)* excludes the first three minutes, when predictive is still gathering evidence and behaves like progressive. *Waiting* = AVAILABLE + RESERVED + DIALING (an agent idle or listening to ringing). *Initiated / Answered / Connected* are calls. *Abandons* are answered calls with no agent free, as a share of answered. *Hung up* = still-ringing calls cancelled by the Safety Controller (not abandons). *Decisions* = Safety Controller verdict counts: Approve / Reduce / Reject / Fallback-to-progressive.
